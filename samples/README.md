# Sample PDFs

The PDFs committed here are the open-access editions of University of Hawaiʻi Press books. Each one carries the Creative Commons license printed on its copyright page (checked 2026-11-03). They are kept unmodified and used only for noncommercial testing of this project. The rest of `samples/` is gitignored, so add a new book on purpose with `git add -f`, after you have recorded its license here.
