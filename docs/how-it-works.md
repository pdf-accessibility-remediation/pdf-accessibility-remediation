These pages explain what each part of the pipeline does, for readers who want more than the [overview](index.md#how-it-works). They cover untagged PDFs, OCR words, the work order the AI writes, the veraPDF checks and the files a run leaves behind.

- [Intake](intake.md): how untagged PDFs get text and tags before the audit.
- [OCR words](ocr-words.md): how OCR words are checked and corrected.
- [Work order](work-order.md): the decisions the AI returns and how they are carried out.
- [Verification with veraPDF](verapdf.md): how the original and the result are checked.
- [Output files](output-files.md): what a run leaves behind.
